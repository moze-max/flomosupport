# flomosupport

这是一个帮助你更好地使用flomo的APP，使用flutter软件开发框架进行开发。

简单来讲，可以帮助你创建模板，使用模板来进行思考与创作，然后使用flomo提供的API将你输入的内容推送到flomo服务器上。

**注意：本应用设计时没有考虑加密，目前只有API密钥采用了加密储存**

## Getting Started

你可以在article页面输入你的密钥，然后在guide页面右上角点击加号，在新的页面里完成你的模板，然后你就可以在guide页面使用你的模板来生成用来输入flomo的文本。

输入flomo的内容包含了模板中你设置的问题，随后就是你所书写的内容。

我希望通过这个软件可以帮助你更好地思考。

## 1、前言
感谢使用flomosupport v0.0.2，期望flomosupport可以为你带来良好的使用体验。

这也许是迄今为止最为强大的一代flomosupport，可以设置头像、可以设置模板类型、可以设置模板图片与模板名字，只需要简单输入flomo为您提供的API，您就可以使用这个软件所提供的模板功能畅快书写您的文字，并且将您的文字一键上传至flomo服务器。

我设计这个软件的初衷是为了良好地使用flomo所提供的开放API，我们设想到这样的一种情况，我们在创作自己的文字的时候，如果存在可以提醒的模板，就像一个清单一样，或许可以帮助您更好表达自己的想法。

我是flomo软件的使用者，正好此软件提供了开放API，因此我就准备设计一个可以用来更好表达自己想法的“模板软件”，这个就是flomosupport软件的由来。

## 3、使用方法

当您进入应用，可以发现进入写作模板界面，同时旁边还存在设置界面。

在使用模板功能之前，您需要先添加您的API，点击设置进入设置页面

然后您需要点击红框所示的项目，进入密钥设置页，然后您需要在这一页输入您的密钥，并且点击保存进行确认。

然后您可以返回主页面了

同时您还可以注意到提醒，“暂无模板，点击右上角加号创建”。

此时您可以点击右上角加号，进入创建新模板界面。

这个是全部的创建新模板页面，如果您的安卓系统设备屏幕比较小，或者您在windows系统上设置的窗口大小比较小，可能会无法完全显示，在安卓系统上，可以通过上下滑动页面的方式查看全部内容，在windows系统上可以通过调整窗口大小的方式查看全部页面。

当您点击添加条目按钮之后会出现下图的弹窗，同时您可以输入内容

当您点击保存之后，您可以在条目显示一栏中看到您所添加的条目，同时还可以删除您曾经添加的条目

您可以自由输入模板、新建并选中分类，并且选择封面图片，最终效果如下图所示。

当您点击保存模板之后会自动返回主页面，显示出当前所有的模板，同时还会提示说已经成功添加了新的模板。

当您点击模板，

您可以自由选择如何输入内容并提交，同时您还可以选择删除当前模板或者将当前模板分享给您的好友或者同事。


当您点击分享按钮将会进入这个选择分享模板的页面，同时选择您心仪的分享模板，之后将模板进行分享。


与此同时，这个软件还提供了更改头像的功能。

在主页面点击左上角三行，进入抽屉页面，然后点击头像就可以进行选择图片设置头像。


您还可以在设置-分类管理中管理您当前所有的分类


在这个页面，您可以移动分类的次序，删除分类，还可以新增分类。
